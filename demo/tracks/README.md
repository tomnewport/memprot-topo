# Demo data tracks

`2j1n-by-resid.csv`: per-residue lipid, water and ion contacts and membrane
displacement for OmpF/2J1N from a MemProtMD coarse-grained simulation in
DPPC (`2j1n_default_dppc-by-resid.csv`, supplied in issue #83), trimmed to
the columns the demo draws and rounded to 3 decimals. MemProtMD:
<https://memprotmd.bioch.ox.ac.uk>.
